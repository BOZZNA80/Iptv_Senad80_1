# IPTV Player (M3U + Stalker/MAC)

APK bauen ohne Android Studio:
1. Neues GitHub-Repo erstellen, den **Inhalt** dieses Ordners hochladen.
2. Tab **Actions** → "Build APK" → Run workflow (läuft auch automatisch beim Push).
3. Fertigen Lauf öffnen → **Artifacts** → `IptvPlayer-apk` → ZIP entpacken → `app-debug.apk` aufs Handy.

Nutzung: M3U-URL oder Stalker-Portal-URL (`http://host:port/c/`) + MAC eingeben → Laden → Kanal antippen.
Nur mit eigenen/legalen Zugangsdaten verwenden.
